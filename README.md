# AI 예산 허브

AI 도구 사용예산의 신청, 부서장 승인, PI팀 검토, 예산 심사, 최종 승인, 구독·집행, 실적보고, 정산·반납을 한곳에서 처리하는 로컬 웹 애플리케이션입니다.

핵심 업무 데이터는 실제 SQLite 파일에 저장되며 외부 DB, 로그인, API 키가 필요하지 않습니다. 최초 실행 시 개인정보를 포함하지 않는 데모 신청 3건과 요금제 참고표가 자동 생성됩니다.

## 기술 구성

- 프런트엔드: React 19, Vite 7, React Router, Lucide 아이콘
- 백엔드: Node.js, Express 5
- 데이터베이스: SQLite (`better-sqlite3`)
- 검증: Vitest, Supertest, Vite production build, Chrome 1280px 렌더링

프런트엔드와 API를 분리하되 하나의 Node 프로세스에서 production build를 제공하도록 구성했습니다. 계산 및 승인 상태 전이는 서버의 SQLite 트랜잭션에서 처리하여 화면 조작만으로 금액이나 처리 순서가 모순되지 않게 했습니다.

## 요구 환경

- Node.js 20.19 이상 또는 22.12 이상
- npm 10 이상

Windows PowerShell, macOS, Linux의 일반 터미널에서 같은 npm 명령을 사용할 수 있습니다.

## 설치 및 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 개발 모드는 Express API(`3001`)와 Vite(`5173`)를 함께 실행합니다.

최초 API 실행 시 `data/ai-budget.db`가 생성되고 샘플 신청 3건이 자동으로 입력됩니다.

### Production 방식 실행

```bash
npm run build
npm start
```

브라우저에서 `http://127.0.0.1:3001`을 엽니다. `npm start`는 빌드된 프런트엔드와 API를 함께 제공합니다.

### 같은 사내망에서 접속

```bash
npm run build
npm run start:lan
```

서버 PC에서는 `http://127.0.0.1:3001`, 같은 사내망의 다른 기기에서는 `http://<서버-PC-IPv4>:3001`로 접속합니다. Windows 방화벽 또는 사내 네트워크 정책에서 3001 포트의 기기 간 통신을 허용해야 할 수 있습니다.

## 샘플 데이터 재생성

기존 로컬 신청 데이터를 삭제하고 최초 데모 상태로 되돌리려면 다음 명령을 실행합니다.

```bash
npm run seed -- --reset
```

기존 데이터는 유지하고 비어 있을 때만 샘플을 생성하려면 다음 명령을 사용합니다.

```bash
npm run seed
```

다른 SQLite 파일을 사용하려면 실행 전에 `DATABASE_PATH` 환경 변수를 절대경로로 설정합니다.

## 주요 사용 흐름

1. 왼쪽 메뉴의 **새 신청서**에서 신청 개요, 목적, 기대효과와 사용자별 예산을 입력합니다.
2. 월 단가와 사용개월을 입력하면 소요액, 기지원 차감, 추가 소요액이 즉시 계산됩니다.
3. 저장 후 상세 화면에서 9단계 진행 현황과 금액을 확인합니다.
4. 오른쪽 위 **역할 전환**을 이용해 신청자, 부서장, PI팀, 경영기획팀, 최종 승인자의 업무를 시연합니다.
5. **업무 처리** 탭에서 현재 역할의 승인·검토·심사를 수행합니다.
6. 최종 승인 후 **집행·사후관리** 탭에서 법인카드 전표, 월 사용량, 결제내역, 실적보고와 정산 조치를 기록합니다.
7. **처리 이력** 탭에서 단계, 처리자, 결정, 의견과 처리시점을 확인합니다.

역할 전환은 데모용이며 외부 인증이나 계정이 필요하지 않습니다. 처리자 이름도 상단에서 변경할 수 있습니다.

## 예산 계산 규칙

- 개인지원 기준: 월 1인당 50,000원
- 사용자별 소요액: `월 단가 합계 × 사용개월`
- 기지원 차감: `MIN(소요액, 50,000원 × 사용개월)`
- 추가 소요액: `MAX(0, 소요액 - 기지원 차감)`
- 실제 부서 추가지원 신청액: 모든 사용자의 추가 소요액 합계

사용자 한 명이 여러 AI 도구를 사용하는 경우 도구·요금제를 함께 기재하고 실결제 예상 월 단가를 합산해 입력합니다. 참고 요금제는 실제 결제액이 아니므로 신청 시점의 VAT·환율 포함 예상액을 확인해야 합니다.

2개월을 초과하는 사용은 예외 사유가 있어야 저장할 수 있습니다. 연간 구독은 비용상 유리한 경우에 한해 사유를 기록하고 승인하는 업무 원칙을 적용했습니다.

## 테스트 및 검증

```bash
npm test
npm run build
```

자동 테스트는 다음을 포함합니다.

- 작성예시 2인 신청 합계 420,000원 / 차감 200,000원 / 추가 신청 220,000원
- 월 30,000원 요금제의 추가 소요액 0원 경계 케이스
- 신청 생성·수정·조회와 SQLite 재연결 영속성
- 부서장 승인 → PI 접수 → PI 검토 → 예산 심사 → 승인·조건부 승인·반려
- 구독·집행 → 실적보고 → 정산·반납
- 잘못된 입력, 역할 위반, 처리 순서 위반 방어

상세 검증 근거는 `ACCEPTANCE_RESULT.md`, 실제 구현·오류·검증 이력은 `WORKLOG.md`에 기록되어 있습니다.

## 프로젝트 구조

```text
server/                 Express API, SQLite 스키마·저장소·seed·계산 규칙
src/                    React 화면과 컴포넌트
tests/                  계산 및 전체 API 업무 흐름 테스트
tools/inspect-xlsx.ps1  reference XLSX 읽기 전용 분석 도구
reference/              원본 Excel 문서(수정하지 않음)
data/                   로컬 SQLite 실행 데이터(자동 생성, Git 제외)
```

## 로컬 데이터와 보안

- 모든 데모 인명에는 `(데모)` 표기를 사용했습니다.
- 핵심 데이터는 브라우저 localStorage가 아니라 SQLite에 저장됩니다. localStorage에는 마지막 데모 역할과 처리자 표시값만 보관합니다.
- 파일 업로드 대신 영수증·전표의 참조번호 또는 내부 보관 위치를 텍스트로 기록합니다.
- 외부 서버, 분석 도구, API 키, Secret으로 데이터를 전송하지 않습니다.
